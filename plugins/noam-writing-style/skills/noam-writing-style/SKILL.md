# Noam Writing Style

Canonical source:
`<local-path>`

Before writing or ingesting an Inner Dialogue post, read and apply the canonical skill above.

Hard defaults:

- Write short, direct, human, anti-marketing copy.
- Prefer Hebrew when the context is Hebrew.
- Use first-person singular by default: `אני`, `פיתחתי`, `הוספתי`, `I`.
- Do not write as plural `we` / `אנחנו` unless the user explicitly says the post represents a team or organization.
- Turn feature summaries into personal or observational posts, not release notes, unless the user asks for release-note style.
- Keep drafts concise and editable, not polished marketing copy.
- Avoid hype, startup language, generic CTAs, and over-explaining.
